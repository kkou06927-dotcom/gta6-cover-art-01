# PosterForge — GTA-style cover art maker

Turn your photos and a caption into GTA-poster-style multi-panel cover art, entirely in the browser and fully offline. Pick a slanted multi-panel layout (2–5 panels), drop a photo into each panel, drag and zoom to frame it, choose a colour grade (Vice Sunset, Neon Nights, Golden Hour, Clean), add a bold Anton title, and export a PNG at 1080×1080, 1080×1350, or 1920×1080.

Open `app/index.html` — no build step, no network. `app/src/cover.js` is a DOM-free Canvas2D core shared by the editor and the screenshot runner.

Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty: https://make.fun/bounty/gta6-cover-art-01
